# 指令执行原理

源：`Main/Util/MacroUtil.ahk` 的 `ExecuteMacroCmdOnce` 及各 `On*`。  
参数说明以 `Web/指令手册.md` 为准，本文补「运行时到底怎么走」。

---

## 1. 宏字符串怎么拆

`SplitMacro` 分隔符：`,` `，` 换行 `⫶`  
空段丢掉。

前缀：

- `🚫` 整条跳过
- `⭐` 调试标记，执行仍走原指令

`GetCmdStr` 会去掉这两种符号再解析。

指令名 = 第一段去掉末尾数字。所以 `搜索3`、`循环12` 都识别成对应类型，数字是序列号。

---

## 2. 两类指令

### 2.1 参数写在字符串里（无独立 ini）

| 指令 | 格式 | 执行函数 |
|------|------|----------|
| 间隔 | `间隔_毫秒` 或 `间隔_A~B` | `OnInterval` |
| 按键 | `按键_键名_按下\|松开\|点击[_时长_次数_间隔]` | `OnPressKey` |
| 移动 | `移动_X_Y_速度_是否相对` | `OnMouseMove` |
| RMT指令 | `RMT指令_类别_指令` | `OnRMTCMD` |
| 注释 | 序列号或文本，函数直接空返回 | — |

### 2.2 第一段是序列号，参数在 JSON

`GetMacroCMDData(序列号)` → 读对应 `*File.ini` → 缓存。  
搜不到序列号会 new 一个默认对象（看起来像「指令在，但参数是默认值」）。

## 3. 逐条说明

### 间隔

- 单值：可变量。随机：`时间1~时间2`。
- 再套 `IntervalFloat`。
- `InterruptibleSleep`：暂停/终止能打断。
- 放在宏末尾 = 每轮循环之间的间隔。

### 按键

1. `SplitCommand` 处理 `Launch_App2` 这类带下划线的键名。
2. 手柄通用名转友好名（`Joy1`→`JoyA` 等）。
3. 按 `ModeArr` 选发送：1 SendNormalKey / 2 SendGameModeKey / 3 SendLogicKey / 4 SendAHIKey。
4. 手柄键走 ViGEm：按钮 / 轴 / 十字键。
5. 类型：按下、松开瞬发；点击耗时 `(时长+间隔)*次数 - 间隔`。
6. 时长再套 `HoldFloat`，间隔套 `PreIntervalFloat`。
7. 「按下时按下」见设置文档。
8. 按下的键记入 `HoldKeyArr`，仅终止或开关结束时统一松开。

要点：按下不是系统自动连发；不松再按可能卡键；点击 <200ms 像单击，>250ms 像长按。

### 搜索 / 搜索Pro

`SearchOnTrigger`：

- 按次数搜。无限次数：一直等到找到，假分支不会走。
- 找到：可选移动/点击，同时把 `TrueMacro` 插进后续指令。
- 没找到且还有次数：`ExecuteMacroCmdOnce` **把本条再插回下一条**（忙等重试）。
- 次数用尽：走 `FalseMacro`。
- 可写结果变量、坐标变量。

搜索 ≠ 开放识别，素材要和屏幕几乎一致。范围小、图小（32×32 / 48×48）更快。  
OpenCV：相似度 0~94 灰度，95~100 带颜色。RMT ImageSearch 很慢。  
窗口搜索可对多个匹配窗口做鼠标动作。

### 移动 / 移动Pro

- 移动：绝对或相对，速度 0~100（100 瞬移），可套坐标浮动。
- 移动Pro：可点 1/2 次、多次相对移动、游戏视角（强制相对+速度 100）。

### 输入

弹窗 / 真假按钮 / 继续 / 继续&取消。  
可暂停当前或全部宏。取消可终止当前或全部。  
弹窗期间 Enter 不会触发其它宏。

### 输出

`{var}` / `{εArr}` 替换后，按类型：SendText、Ctrl+V、ToolTip、指令窗、弹窗、语音、剪贴板。

### 循环

按 `LoopCount` 跑 `LoopBody`。  
继续条件：条件不成立则本轮不跑体。  
退出条件：条件成立则离开循环。  
体内「如果」的流程控制可跳过本轮或跳出。  
内层 `循环次数` 变量表示当前是第几轮。

### 宏操作

| CallType | 行为 |
|----------|------|
| 插入到当前宏 | 把目标 `MacroArr` 重复 `InsertCount` 次，作为返回值插入当前流（并行不增加） |
| 触发 | `MyTriggerSubMacro`，另一条宏同时跑 |
| 暂停 / 取消暂停 / 终止 | 改目标宏状态 |

目标用 `MacroType` + `Index`，并用 `MacroSerial` 校正序号错位。  
`当前宏` 指正在执行的这一条。子宏页签自己没有热键。

### 变量

最多 4 路。类型以代码为准：1 数值 2 随机 3 字符 4 系统 5 删除。  
`IsIgnoreExist` 为真且变量已在则跳过。系统变量只读。

### 变量提取

OCR/剪贴板/窗口文本，按 `&x` `&c` 模板写入最多 6 个变量。  
失败：新变量=0，旧变量不动。也可按次数重试（返回重插本条）。

### 如果 / 如果Pro

如果：最多 4 条件，且/或，真假双分支 + 流程控制 + 可选保存 1/0。  
如果Pro：多分支自上而下，都假走默认。  
比较：> >= == <= < 包含 变量存在 正则。

### 运算

表达式求值写入结果变量，源变量不变。

### 运行

1 直接 Run；2 RunWait 存退出码；3/4 管道 stdin，4 还可存 stdout/stderr。  
窗口选项：隐藏/普通/最小化/最大化。路径支持变量替换。

### 文件读写 / 文本处理 / 数组

见指令手册。数组下标从 1，`MainIndex=0` 表示整个数组。

### RMT指令

`RMT指令_类别_指令`。可调截图、OCR 到剪贴板、自由贴、指令窗、菜单、键鼠总开关（需管理员）、休眠、暂停/恢复/终止全部、重载、退出。  
键鼠类走 `ApplyRmtInputControl`，不再广播成普通 RMT 动作。

### 后台鼠标 / 后台按键

对指定窗口发消息，不带动真实键鼠。很多游戏/部分窗口无效，常需管理员。  
后台按键的按下/点击规则与前台按键相同（要配对松开）。

### 窗口管理

按 `标题⎖类名⎖进程名` 找窗，再激活/改大小/置顶/透明度/穿透等。关闭窗口不等于杀进程。

### 按键检测

物理=手指或罗技驱动；逻辑=再加宏模拟。结果写入变量 1/0。

### 抓图

屏幕或窗口区域保存 PNG，路径可进变量，供后续搜索当图片源。

### 图形开始节点

`OnTriggerGraphMacro`：沿节点图走，分支可并行（多 Worker）。  
线性宏是一条队列；图形宏是图 + 引用计数，计数回 0 才结束。

## 4. 流程控制标记（写在该条宏的 VariableMapArr）

| 标记 | 谁设置 | 效果 |
|------|--------|------|
| `循环-跳过本轮` | 如果 / 如果Pro | 结束当前循环体或当前宏轮 |
| `循环-跳出` | 同上 | 离开循环或离开整个宏循环 |
| `分支-跳出` | 同上 | 离开当前 `OnTriggerMacroOnce` |
| `宏循环次数` | 执行框架 | 外层第几轮，从 1 |
| `循环次数` | 循环指令 | 内层第几轮 |

## 5. 耗时与丢失

系统来不及处理会丢指令。建议：

- 点击时长 ≥ 100ms，不要低于 30ms
- 点完按钮后再搜，后面加 ≥ 500ms
- 宏末尾加约 200ms
- 平时多插 100ms 间隔

搜索耗时 ≈ (单次检索 + 间隔) × 次数 − 间隔。  
点击耗时 ≈ (时长 + 间隔) × 次数 − 间隔。

---

## 6. 失败时看起来像「没执行」的原因

1. `🚫` 或注释
2. 未知指令名 / JSON 序列号对不上（读到默认空对象）
3. 变量不存在且没开提醒 → 该条中途 return
4. 已被杀或暂停
5. 仅前台运行宏，窗口切走
6. `try/catch` 吞掉异常
7. 按键类型在目标程序无效
8. 搜索一直重试（无限次数）看起来像卡死

---

## 7. 指令与页签无关

任何页签的 `MacroArr` 都走同一套 `Actions`。  
差别只在**怎么被触发**（热键 / 字串 / 轮盘 / 浮窗 / 定时 / 宏操作）。
