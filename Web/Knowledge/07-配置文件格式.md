# 配置文件格式

机器人要分析用户配置，从本文开始。  
源：`InitFilePath`、`LoadMainSetting`、`ReadTableItemInfo`、`GetMacroCMDData`。

---

## 1. 目录

```
<RMT根目录>/
  Setting/
    MainSettings.ini          ← 全局软件设置（所有方案共用）
    <方案名>/                 ← 例如「RMT默认配置」
      MacroFile.ini           ← 各页签宏列表
      SearchFile.ini
      SearchProFile.ini
      MMProFile.ini
      OutputFile.ini
      RunFile.ini
      LoopFile.ini
      SubMacroFile.ini
      VariableFile.ini
      ExVariableFile.ini
      CompareFile.ini
      CompareProFile.ini
      OperationFile.ini
      BGMouseFile.ini
      BGKeyFile.ini
      TextOpsFile.ini
      TimingFile.ini
      ArrayFile.ini
      InputFile.ini
      FileIOFile.ini
      WindowManageFile.ini
      KeyCheckFile.ini
      CommentFile.ini
      ScreenShotFile.ini
      GraphNodeFile.ini
      GraphStartNodeFile.ini
      Images/ScreenShot/      ← 搜索素材、RMT指令截图
      Images/TempShot/        ← 抓图指令输出（执行写这里，不是 JSON 的 SavePath）
      Images/UseExplain/
      使用说明&署名.txt

```

`.rmt` = 把某个 `<方案名>` 文件夹打包后的分享文件。导入后仍是上述结构。

---

## 2. INI 通用规则

- 节名固定：`[UserSettings]`（变量 `IniSection`）
- 编码：AutoHotkey `IniRead`/`IniWrite`，中文常见 UTF-16
- 数组：`π` 拼接，按下标 1..n 对齐
- 布尔：`0`/`1` 或 `true`/`false`（读盘后会转）
- JSON：复杂对象整段当值，一行

---

## 3. MainSettings.ini（全局）

键名与 `MainConfig` 字段基本同名，例外：

| ini 键 | 字段 |
|--------|------|
| `RecordMacroHotKey` | `ToolRecordMacroHotKey` |
| `ToolTextFilterHotKey` | 同名 |
| `OCRType` | `OCRTypeValue` |
| `KeyDownDown` | `KeyDownDownType` |
| `CMDTip` | 存在 SoftData 与 MainConfig 两侧 |

`CurSettingName` 决定加载哪个子目录。  
`SettingArrStr` 是方案列表。  
分析「某条宏」时，全局项只在解释浮动、多线程、管理员、手柄类型时需要。

---

## 4. MacroFile.ini（宏列表）

每个页签一套键，前缀是 `TabSymbol`：

`Normal` `String` `Menu` `UI` `Timing` `SubMacro` `Replace`

### 4.1 数组键（π 分隔，下标对齐）

`{前缀}TKArr`  
`{前缀}ModeArr`  
`{前缀}ForbidArr`  
`{前缀}RemarkArr`  
`{前缀}LoopCountArr`  
`{前缀}HoldTimeArr`  
`{前缀}TriggerTypeArr`  
`{前缀}SerialArr`  
`{前缀}TimingSerialArr`  
`{前缀}StartTipSoundArr`  
`{前缀}EndTipSoundArr`  
`{前缀}IcoPathArr`  
`{前缀}UnorderedTriggerArr`

第 i 个元素 = 该页签第 i 条宏。

### 4.2 宏内容（一条一个键）

`{前缀}MacroArr{i}`  

例如 `NormalMacroArr1=按键_a_点击_100_10_200,间隔_3000`  
换行在文件里是 `⫶`。

按键替换页：内容是 `原键,目标键`，不是指令流。

### 4.3 模块

`{前缀}FoldInfo` = `ItemFoldInfo` 的 JSON。

没有 FoldInfo 时，软件会写入默认模块（一条「RMT默认初始化配置」），并把内置示例宏填进去。

---

## 5. 指令 JSON 文件

节 `[UserSettings]`，键 = `SerialStr`（如 `搜索3`、`Timing1`、`循环2`），值 = 一整段 JSON。

例：

```ini
[UserSettings]
搜索1={"SerialStr":"搜索1","SearchType":1,"Similar":90,...}
```

读法：

1. 从 `MacroArr` 拆出 `搜索1`
2. 去掉数字得到类型「搜索」
3. 打开 `SearchFile.ini`，读键 `搜索1`
4. 用 `01-DataClass数据结构.md` 解释字段

序列号对不上（复制后没重分配、合并半残）→ `IniRead` 为空 → 运行时 new 默认对象 → 用户觉得「指令在但行为不对」。

**间隔 / 按键 / 移动 / RMT指令** 没有这种文件。

---

## 6. 如何从一段 MacroArr 还原逻辑

例：

```
搜索2,间隔_200,按键_a_点击_100,循环1
```

1. `搜索2` → SearchFile.ini → 看图/色/文、范围、真假分支
2. `间隔_200` → 等 200ms（再乘间隔浮动）
3. `按键_a_点击_100` → 点 a 键 100ms（缺次数、间隔则走默认）
4. `循环1` → LoopFile.ini → `LoopBody` 里可能还有嵌套指令

图形宏：`MacroArr` 里往往是 `图形开始节点1`，再读 `GraphStartNodeFile.ini` 的 `NodeArr`，逐个读 `GraphNodeFile.ini` 的 `CurCMD`。

---

## 7. 用户可能发来的形态

| 用户发什么 | 怎么处理 |
|------------|----------|
| 整夹 `Setting` | 先看 `MainSettings.ini` 的 `CurSettingName`，再进对应子目录 |
| 单个 `MacroFile.ini` | 能看列表和触发，复杂指令缺 JSON 只能讲到序列号 |
| 某个 `SearchFile.ini` | 只能讲搜索参数，不知道挂在哪条宏上 |
| `.rmt` | 当方案文件夹，先当 zip/包解开再按上面读 |
| 只发指令串 | 按 `05` 拆指令；有序列号就请用户再发对应 ini |
| 截图主界面 | 看禁用勾选、前台、触发类型、色块，不必先读文件 |

---

## 8. 默认未保存方案（对照「新装不能用」）

`HasSaved=false` 且 FoldInfo 空时写入：

- 按键宏：触发 `k`，禁用，类型按下，循环 1，内容 `按键_a_点击_100_10_200,间隔_3000`
- 其它页签也有类似示例

所以「按 k 没反应」先看是不是还在禁用。
