# 常见报错Q&A

本文档整理了使用过程中常见的错误提示与异常问题，并提供相应的解决方法。

---

## 运行报错1

下载软件压缩包，未解压运行

![问题截图](/RMT/Web/Images/Question/Unzip1.png)

**原因：**
下载zip包后，直接浏览zip包里面的文件，并运行若梦兔应用程序

**解决方法：**
- 解压后再运行软件
---

## 运行报错2
运行若梦兔应用程序报错
![问题截图](/RMT/Web/Images/Question/Init.png) ![问题截图](/RMT/Web/Images/Question/Init1.png)

**原因：**
若梦兔文件放在受保护的文件夹中，导致若梦兔运行时没有创建文件夹的权限、没有访问自己配置文件的权限
**解决方法：**
- 更换若梦兔文件的存放位置
- 移除相关文件的保护限制：window安全中心 -> 病毒和威胁防护 -> 管理设置 -> 文件夹限制访问 -> 受保护的文件夹，找到对应的文件夹并移除
---

## 运行报错3

通过阿里云盘或者百度网盘下载软件文件不全 或者 系统误杀删除部分文件

![问题截图](/RMT/Web/Images/Question/Cloud.png) 

**解决方法：**
- **设置**->**文件校验**自动补齐缺失文件
- 通过开源网址的发行版处重新下载软件
- 通过软件交流群中的群文件重新下载软件
---

## 配置迁移报错

低于1.0.8版本配置迁移到1.0.8版本中

![问题截图](/RMT/Web/Images/Question/Update.jpg) 

**解决方法：**

- 不支持低于1.0.8版本配置迁移到1.0.8及以上版本，请重新配置

## Excel读写失败

Windows存在UAC（用户账户控制）隔离

![问题截图](/RMT/Web/Images/Question/ExcelLock.png) 

**解决方法：**
- Excel表格以管理员权限打开，若梦兔（RMT）软件也需要以管理员权限打开
- Excel表格以非管理员权限打开，若梦兔（RMT）软件需要以非管理员权限打开

## 抓图 / 搜图失败（OpenCV）

抓图指令或搜索图片时报 OpenCV 不可用、dll 加载失败，或抓完 `Images\TempShot` 里没有图。

**原因：**
- 未解压完整、杀毒删了 `Plugins/OpenCV`
- 测试版（版本号带 F）和正式资源对不上
- 把「抓图」失败当成要改设置里的「截图方式」（抓图不走这项）

**解决方法：**
- 设置 → 文件校验，补齐 OpenCV 插件
- 从 GitHub / Gitee 发行版重新下载完整包
- 抓图看 `Setting\<当前方案>\Images\TempShot`；安装目录没写权限时看用户临时目录 `RMT_TempShot`
- 工具热键截图、RMT指令「截图」报错，才去设置里换微软 / RMT / SC
