# 常见问题Q&A
本文档整理了使用过程中常见的问题，并提供相应的解决方法。
---

## 配置无法生效
正常配置触发键和宏配置后，按下触发键无法触发宏执行
即按下触发键后，对应宏配置序号位置没有出现绿色色块
**解决方法：**
- 宏配置右侧`禁用`取消勾选
- 宏配置模块中`禁用`取消勾选
- 宏配置模块中的`前台`内容清空（除非你知道前台的作用）
- 配置后需要`应用并保存`配置才会生效

> 提示：不支持覆盖文件更新软件，覆盖内容更新也出现宏触发无效（请使用软件的配置迁移，或导出导入同步配置）
---

## 游戏中配置无效
在记事本中可以正常触发，但在游戏中无法触发或触发后配置不生效。
**解决方法：**
1. 以管理员身份运行RMT(若梦兔)软件
2. 运行`GHUB`、进入若梦兔宏配置，修改宏按键类型->`罗技`确定后，左下角应用并保存
3. 按键类型 -> `AHI`确定后，左下角应用并保存
4. 如以上方法无效，请执行1、2 或者 1、3：以管理员身份运行软件 + 修改宏按键类型
---

## 部分按键无效
安装360、火绒、腾讯电脑管家等安全软件后，若梦兔宏按键鼠标左键、右键、回车键等等可能无效
**解决方法：**
1. 关闭安全软件
2. 把若梦兔软件添加到安全软件的白名单中
---

## 罗技按键无效（键盘 / 鼠标）

按键类型选择「罗技」时，键盘与鼠标都依赖 **G HUB 2022.2.1154 及更早版本**。  
装成新版后，罗技模式下的键盘、鼠标往往都会失效。

### 解决方法

1. **安装旧版 G HUB**（交流群文件可下载）
2. 打开 **设备管理器**，确认能看到罗技的两个 GHUB 虚拟设备（如下图）。  
   看不到这两个设备时，罗技功能无法使用。

![设备管理器中的 GHUB 虚拟设备](/RMT/Web/Images/Question/Logitech.png)

3. 若没有上述设备：到系统「安装的应用」中卸载 G HUB，再重新安装旧版，直到设备管理器中出现这两个虚拟设备为止。
4. **运行「禁用 G HUB 更新」脚本**（交流群文件可下载），尽量避免被自动升到新版。

> **提示**：仅在 G HUB 软件里关掉更新有时会失效。一旦被升级到新版本，请重新安装旧版，并再次运行禁用更新脚本。

## 指令丢失
宏指令执行过于紧凑时，可能会导致部分指令未被系统识别或执行。
原因： 系统处理指令需要时间，若指令之间没有合理间隔，后续指令可能被丢弃。
### 解决方法
在指令之间增加适当的**间隔**，可以有效提升宏执行的稳定性。
### 推荐建议
| 场景 | 推荐值/做法 |
|------|-------------|
| 宏按键点击时长（按下到松开） | 推荐 **100ms** |
| 宏按键点击时长（最低不建议） | 低于 **30ms** 易丢失 |
| 移动类指令 | 本身不消耗时间，建议添加间隔确保移动完成后再执行后续指令 |
| 宏末尾（不影响功能前提下） | 增加 **200ms** 间隔，有助于避免状态异常 |
| 通用习惯 | 不追求极限速度时，多插入**100ms**间隔是良好的习惯 |
> 提示：适当增加间隔不会明显影响使用体验，但能显著提高宏的可靠性。

## 宏按键状态说明
宏配置结束后，请确保所有宏按键都已**松开**，否则可能配置失效或按键卡住（除非刻意需要保持按下状态）。
### 宏按键状态行为定义
| 行为 | 说明 |
|------|------|
| 按下 | 触发按下。未松开再次按下可能导致指令无效 |
| 点击 | 按住时间 ≤ 300ms |
| 长按 | 按住时间 ≥ 500ms |
